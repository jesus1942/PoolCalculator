La vista de detalle del proyecto concentra la operación técnica, comercial y documental de una obra de piscina. Desde acá se revisa el modelo, se calculan materiales, se seleccionan equipos, se asigna mano de obra y se generan entregables.

Si al abrir el proyecto faltan configuraciones base y existe un modelo de pileta asociado, la pantalla puede autogenerar configuración eléctrica, hidráulica y de losetas y guardarla de forma automática.
